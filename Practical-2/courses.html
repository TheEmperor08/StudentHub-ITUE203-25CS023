Syllabus outline

CSUC201 – Fundamentals of Data Structure and Algorithm (FDSA)

Linear and non-linear data structures including stacks, queues, linked lists, trees and graphs, and basic algorithmic complexity.

ITUE203 – Web Development Frameworks (WDF)

Front-end and back-end web technologies: semantic HTML5 structure, styling, responsive layouts and JavaScript frameworks.

CEUE203 – Object Oriented Programming (OOP)

Classes, inheritance, polymorphism, encapsulation, abstraction and file handling.

ITUC201 – Fundamentals of Computer Networks (FCN)

OSI and TCP/IP models, network protocols, routing, IP addressing and transport layer security.

MSUD203 – Discrete Mathematics and HSUV201 – Creativity (HS)

Mathematical logic, set theory and combinatorics, and creative engineering problem-solving.
