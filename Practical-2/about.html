About StudentHub

Purpose

Students of the CSE department need a single place to see their timetable, enrolled subjects, attendance, results, assignments and campus notices. Administrators need a secure way to manage student records, events and user accounts. StudentHub brings these together in one web portal with role-based access.

Who uses StudentHub

Visitor
Views the home page, registers, logs in and sends inquiries.
Student
Views the dashboard, timetable, attendance, results, assignments and events, and manages the profile.
Faculty
Planned: manages courses, assignments and attendance.
Admin
Manages student records, events and user accounts, and reviews the audit log.

Main modules

  • Public portal: Home, About, Events, FAQ, Contact, Feedback
  • Accounts: Login, Register
  • Student area: Dashboard, Profile, Courses, Attendance, Assignments, Results, Notices, Directory
  • Administration: Admin Console
