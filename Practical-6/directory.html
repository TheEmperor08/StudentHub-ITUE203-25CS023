StudentHub

Campus Data Directory

Students, events and FAQs loaded from JSON files with the Fetch API – search, filter, sort and browse page by page.

Please open this page through the local server

Browsers block fetch() and JavaScript modules for pages opened directly from a folder.

  1. Double-click start-server.bat in the Practical-6 folder, or run python -m http.server 8606 in that folder.
  2. Open http://127.0.0.1:8606/directory.html.

All three datasets are sample data: the students, IDs (DEMO-001…) and CPI values are fictional.

Testing tools (loading, error and cache)

The last successful response of each dataset is saved in localStorage. If loading fails, that saved copy is shown with a notice; after clearing it, the error message appears instead.
